How to use

Step 1: Copy the CDN link 
<script src="https://cdn.jsdelivr.net/npm/kinex.js/dist/kinex.min.js"></script>
Step 2: Use the component code 
<div data-kinex="option-wheel"
     data-items="Ambient,House,Techno"></div>

<script>
  Kinex.init();
</script>
